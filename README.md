# Dhasharathi K — UAV Portfolio

A responsive, static portfolio website built from the résumé and supplied photographs. It uses HTML, CSS, and JavaScript only: no paid hosting, build tools, database, or framework.

## Grounding / accuracy
- Resume claims and experience are based on the supplied `Dhasharathi_K_Resume.pdf`.
- Photographs are the four supplied images, included in `assets/`.
- Instagram button points to the exact profile URL supplied by the user: https://www.instagram.com/dk_rc_stories/
- Instagram content could not be reliably inspected in this build, so no extra claims were inferred from posts.
- The website does not claim performance metrics, certifications, project outcomes, or details that are not present in the supplied résumé.
- Contact details from the résumé are displayed. Review whether you want your phone number and email public before publishing.

## Preview locally
Extract the ZIP and open `index.html` in a browser. Or, from this folder:
```bash
python3 -m http.server 8000
```
Open http://localhost:8000.

## Publish for free with GitHub Pages
1. Sign in or create a GitHub account at https://github.com/.
2. Create a **public** repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your GitHub username).
3. Extract this ZIP. Upload `index.html`, `style.css`, `script.js`, the `assets/` folder, and this README to the repository root. Keep the assets folder structure intact.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for GitHub Pages to finish deploying. Open `https://YOUR_USERNAME.github.io`.
8. If you change files later, commit/upload the updates and wait for deployment to refresh.

Official documentation: https://docs.github.com/en/pages/quickstart

## Before sharing publicly
- Confirm all resume details and contact information are appropriate for public display.
- The supplied group photograph has faces obscured/pixelated in the provided image. Keep it only if you have permission to publish it.
- Verify the content of the Instagram account and update any missing details yourself if desired.
- Optional: add a public resume PDF, project schematics you own, and demo videos that are safe to share.
