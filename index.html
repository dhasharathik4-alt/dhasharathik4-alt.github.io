PRJ-01UNMANNED GROUND SYSTEM · RESCUE & SURVEILLANCE

AquaBot — Rescue & Surveillance Rover

A remotely operated and autonomy-capable rover for rescue and surveillance tasks. The platform integrates an ArduPilot flight-controller stack for navigation and control, a telemetry link to the operator, live FPV video, and servo-driven robotic mechanisms on a custom 3D-printed structure.

PRJ-02EMBEDDED SYSTEMS · AVIONICS

Custom Flight Controller & Telemetry

Flight-controller concepts and telemetry solutions built around an STM32 microcontroller. The architecture combines inertial, barometric, magnetic and GNSS sensing with UART/CAN interfaces, onboard data logging and ground-control-station integration.

Engineering scope

  • Hardware architecture: sensor selection and bus topology around an STM32-class MCU.
  • Firmware-level sensor integration and serial/CAN communication on the embedded target.
  • Telemetry and logging pathway to a ground-control station for analysis and debugging.

Technical focus

  • State estimation inputs — IMU, barometer, magnetometer and GPS provide the measurements a controller needs for attitude, altitude, heading and position.
  • Interfaces — UART for peripherals and telemetry; CAN for robust multi-node avionics communication.
  • Observability — data logging for post-flight analysis and tuning.

Integration of FlightGear flight data with an autonomous UAV simulator, with LabVIEW used to model the telemetry path from the simulated aircraft to a ground control station. XML definitions and Wireshark packet inspection were used to verify the data exchanged.
